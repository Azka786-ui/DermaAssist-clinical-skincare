# DermaAssist — Clinical Skincare

A modern, responsive clinical skincare website with a clean, premium, and user-friendly design.

## 🌐 Live Demo

[derma-assist-clinical-skincare.vercel.app](https://derma-assist-clinical-skincare.vercel.app)


## ✨ Features

* Modern and responsive design
* Skin concerns exploration
* Skincare product discovery
* Product detail pages
* Light & dark mode
* Responsive navigation
* Interactive UI sections
* Video integration
* Mobile, tablet, and desktop support

## 🛠️ Built With

* React.js
* TypeScript
* Tailwind CSS
* Vite
* HTML & CSS
* Git & GitHub
* Antigravity AI

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Azka786-ui/DermaAssist-clinical-skincare.git
```

### 2. Open the project

```bash
cd DermaAssist-clinical-skincare
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
